# SRI SHAKTHI SYSTEM AND SERVICE - Website

A professional, modern website for SRI SHAKTHI SYSTEM AND SERVICE, specializing in computer, laptop, and printer sales, service, and rental in Chennai.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, professional design using Tailwind CSS
- **WhatsApp Integration**: Direct WhatsApp API integration for instant customer communication
- **SEO Optimized**: Complete on-page SEO with meta tags, schema markup, and sitemap
- **Interactive Elements**: Chatbot, floating WhatsApp button, and smooth animations
- **AIDA Framework**: Marketing copy structured using Attention, Interest, Desire, Action formula

## 🚀 Deployment Instructions

1. **Upload Files**: Upload all files to your web hosting server
2. **Domain Setup**: Point your domain to the hosting server
3. **SSL Certificate**: Enable HTTPS for security
4. **Email Setup**: Configure contact form email functionality
5. **Brand Logos**: Replace placeholder logos in `/assets/images/` folder
6. **Google Analytics**: Add tracking code if needed
7. **Social Media**: Update social media links in footer

## 📧 Contact Form Setup

The contact form requires server-side processing. Options include:

1. **PHP Mailer**: Use a simple PHP script to send emails
2. **Formspree**: Third-party form handling service
3. **Netlify Forms**: If hosting on Netlify
4. **Custom Backend**: Node.js, Python, etc.
